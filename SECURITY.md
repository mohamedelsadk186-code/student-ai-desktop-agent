# Security Policy

## Supported Versions

The project is currently supported for the latest released version.

## Reporting a Vulnerability

Please report security issues privately by emailing the maintainer or by opening a private security report through the repository if available.

Do not disclose security issues publicly until they have been investigated and a fix is available.

## Scope

This project includes:
- Electron desktop app
- Express backend
- SQLite local database
- API integrations with AI providers

Please avoid sharing secret keys, tokens, or environment values in public issues or pull requests.
